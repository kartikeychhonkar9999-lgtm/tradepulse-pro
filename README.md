# TradePulse Pro — Nifty F&O & MCX Crude Oil Pattern AI

## Features
- **All-Patterns Scanner:** Scans Candlestick (Hammer, Engulfing, Morning/Evening Star, Three Soldiers/Crows, Harami, Piercing, Dark Cloud, Tweezers, Marubozu), Reversal (Double/Triple Top & Bottom, Head & Shoulders, Inverse H&S, Falling/Rising Wedge, Broadening Formation), Continuation (Ascending/Descending/Symmetrical Triangles, Pennant), and Harmonic (ABCD) patterns.
- **Strict Strong-Signal Filter:** Outputs `STRONG BUY` or `STRONG SELL` ONLY when high-conviction confluence is met; otherwise outputs `NO SIGNAL`.
- **Dedicated Analyze Button:** Tap `ANALYZE ALL PATTERNS & GET SIGNAL` on any chart or Option Chain strike.
- **Auto-Build Android APK on GitHub:** Includes `.github/workflows/build-apk.yml`.
